# pratj-skills — Claude Code plugin marketplace

A personal marketplace of design, front-end, and workflow skills for Claude Code —
so they work on **any machine and on cloud/web**, not just one desktop.

## Install (on any machine, or claude.ai/code cloud)
```
/plugin marketplace add prathmeshgupta/claude-skills
/plugin install <plugin>@pratj-skills
```

## Plugins
| Plugin | What | Skills |
|---|---|---|
| `motion` | Purposeful UI motion & animation — build, review, and vocabulary (Emil Kowalski / Apple-style). | 12 |
| `design-taste` | Anti-slop visual design: taste, brand systems, redesigns, DESIGN.md brand library, and design-image direction. | 14 |
| `frontend-quality` | Front-end quality: the Front-End Checklist, performance, web-interface & writing guidelines, React patterns, rare UI. | 11 |
| `vercel` | Deploy to and optimise Vercel (CLI, tokens, cost/perf). | 3 |
| `dev-workflow` | How you work, not what you build: laziest-senior-dev minimalism (ponytail), ADHD-friendly answers, architecture diagrams. | 10 |

Install one plugin, several, or all — you don't have to carry every skill on every
machine. Sources are credited in each skill's own SKILL.md.

> **Note:** the `graphify` skill in `dev-workflow` needs the CLI first: `uv tool install graphifyy` (or `pipx install graphifyy`), then `graphify install`.
